# Hospitality Intelligence

## Purpose

RADR handles machine work (notes, allergies, seating, timing) so teams can focus on welcome, recognition, and care.

## Categories

1. **CRITICAL** — explicit allergy / safety communication
2. **PREPARE** — private room, accessibility, seating setup
3. **RECOGNIZE** — birthday, anniversary, engagement, returning guest
4. **INFORM** — minor preference

## Allergy rules

- Never infer a medical allergy
- Never treat preference / vegan / religious restriction as allergy
- Separate **CONTAINS** vs **POSSIBLE CROSS-CONTACT** vs **UNKNOWN**
- Never label a dish “safe” — prefer “No identified … in current menu data · confirm with kitchen”
- Ambiguous notes (“No nuts please”) → needs clarification, not allergy assumption
- Prior-visit allergy → reconfirm tonight

## Access

Finance / CFO: no individual allergy detail.  
FOH / GM / kitchen: role-minimized operational views.

## Control Center

Surface only when confirmation / kitchen ack / clarification is missing.  
Otherwise: quiet “Safety ready”.
