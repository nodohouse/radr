# Public site purpose audit

Canonical page jobs for the RADR marketing site. Every route must obey this. Do not invent parallel stories.

**PRIMARY QUESTION:** What is RADR and why should I care?

**WHAT THIS PAGE OWNS**
- Category: Verified Decision Intelligence for hospitality
- The Decision Gap
- Systems → RADR → Decision (Connect)
- Signals → Decision story
- Product proof
- Hospitality context
- Value Calculator teaser
- Final CTA

**WHAT IT MUST NOT REPEAT**
- Full Platform surface tour
- Full leak-class economics deep-dive
- Commercial packaging / matrix
- Company founder narrative

**SECONDARY CTA:** See how it works  

**KEY VISUAL:** Continuous atmospheric canvas + Decision product theater (mockup fidelity)

## Cross-page rules

1. Continuity via gradient atmosphere, shared grid/type/buttons — not background signal lines.
2. Each page advances the story; do not re-explain systems → RADR → Decision in full on every route.
3. CTA discipline per page — do not sprinkle five competing CTAs.
4. Absolute positioning = decoration only. Content = Grid / Flex.
