## Positioning

RADR is built **across hospitality**. Core public examples: Restaurants + Hotels. Architecture: broader hospitality (groups, resorts, serviced apartments, bars/clubs where the model applies). Never imply equal production readiness for every adjacent vertical.

Visitor must never leave thinking RADR is “hotel software” or “restaurant software.”
