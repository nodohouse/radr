## North star (honest)

Understands what matters.

Prepares or executes the response.

> If truth exists in software: **CONNECT IT.**  
> If truth exists physically: **CAPTURE IT.**

## Multilingual architecture (design now, ship later)

```
INPUT LANGUAGE  →  CANONICAL OPERATIONAL TRUTH  →  DISPLAY LANGUAGE
```

Rules:

- Do not hardcode English into core domain object fields meant for operators  
- UI locale ≠ evidence language  
- Prepares restaurant staff, housekeeping, maintenance, multi-country groups  
- Full mobile multilingual UX is **out of scope** for current alignment pass

## Autonomy communication

Always present the ladder as **governance**:

| Stage | Public language |
|---|---|
| Observe | RADR is watching |
| Recommend | Ready when you are |
| Prepare | Prepared for approval |
| Approve required | Waiting on … |
| Auto-act within policy | Handled automatically (policy) |

Approval is a **strength**, not a limitation.
