# DATA VISUALIZATION SYSTEM

**Date:** 2026-09-24  
**Product:** RADR Visual System 3.0

## Chart grammar

| Element | Treatment |
|---------|-----------|
| Observed | Near-black solid |
| Forecast | Soft dashed green |
| Range / uncertainty | Low-opacity band |
| Plan / expected | Stone dashed |
| NOW | RADR green marker |
| Decision | Triangle + chip (label off-plot) |
| Context events | Dots + chips above chart |
| Grid / period bands | Near-invisible |
| Negative business | Semantic red |
| Risk | Amber |

## Live trajectory

- Protagonist of Live
- Labels never pile on the plot — annotation chips above SVG
- Axis skips ticks that collide with NOW
- Heat labels only when segment is wide enough
