# Marketing Truth Audit (V3)

**Rule:** Every public claim must be defensible. No invented traction.

---

## Prohibited unless verified

- Customer logos / “trusted by”
- User / hotel / restaurant / country counts
- Recovered value totals or ROI averages as proof
- Testimonials / case studies / certifications
- Implying logos = customers, partners, or certified integrations
- Presenting calculator output as Verified Value
- Guaranteed savings language

---

## Allowed trust builders

- Specific product behavior (demos clearly labeled Illustrative)
- Transparent calculator methodology + assumptions
- Evidence lineage · Data Health · autonomy ladder
- Human approval / policy language
- No rip-and-replace positioning
- Public methodology pages

---

## Labeling standards

| Surface | Required label |
|---------|----------------|
| Hero Decision / sticky loop | Illustrative RADR demo |
| Integration logos | Representative systems. Availability varies. |
| Calculator results | Illustrative estimate. Not a guaranteed outcome. |
| Verified in calculator | Always $0 until product seals |
| Global cities (Company) | Demo operating contexts — not customers |
| Ticker | ILLUSTRATIVE RADR SIGNALS |
