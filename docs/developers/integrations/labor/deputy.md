# Deputy

**Last reviewed:** 2026-08-24  
**Official documentation:** https://developer.deputy.com/  
**RADR status:** planned  
**API access type:** PUBLIC_API

Deputy exposes a public REST API (OAuth 2.0 or permanent token). Strong candidate for RADR's first real labor adapter.

## Data RADR wants

Location, role IDs, scheduled/actual shifts, breaks, labor cost. Minimize HR PII.

## Credentials (placeholders)

```
DEPUTY_CLIENT_ID=your_client_id
DEPUTY_CLIENT_SECRET=your_client_secret
# or
DEPUTY_API_TOKEN=your_api_token
```

## Implementation

**Not shipped.** Follow official OAuth / permanent token guides when building.
